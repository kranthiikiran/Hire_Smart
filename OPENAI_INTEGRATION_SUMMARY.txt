HOW IT WORKS NOW
═══════════════════════════════════════════════════════════════════════

ANALYSIS FLOW:
1. Resume uploaded → Text extracted (PDF/DOCX/TXT)
2. Traditional NLP runs (TF-IDF + cosine similarity + skill matching)
3. IF OpenAI configured:
   a. GPT extracts skills with context understanding
   b. GPT assesses experience and cultural fit
   c. GPT provides semantic similarity score
   d. Blended score calculated
   e. Additional insights added to result
4. ELSE: Traditional NLP result returned (no errors)

WHAT OPENAI ADDS (NEW CAPABILITIES)
═══════════════════════════════════════════════════════════════════════

1. CONTEXTUAL SKILL EXTRACTION
   - Understands implied skills (e.g., "led agile team" = agile, leadership)
   - Recognizes skill synonyms and variations
   - Extracts soft skills better than keyword matching

2. SEMANTIC SIMILARITY (DEEPER UNDERSTANDING)
   - Uses language model embeddings
   - Understands context, not just keywords
   - Better handles creative job descriptions

3. EXPERIENCE ASSESSMENT
   - Nuanced evaluation of years + relevance
   - Assesses quality of experience, not just duration
   - Identifies leadership and impact indicators

4. CULTURAL FIT INDICATORS
   - Extracts values and work style mentions
   - Identifies collaboration patterns
   - Notes innovation and learning mindset

5. MISSING CRITICAL SKILLS
   - GPT identifies which missing skills are deal-breakers
   - Prioritizes based on job requirements

6. CONFIDENCE SCORING
   - GPT provides confidence level (0-100) on recommendations
   - Helps prioritize which candidates to review first

7. BLENDED SCORING
   - 60% Traditional NLP (proven, reliable)
   - 40% GPT Semantic (context-aware)
   - Best of both worlds

SETUP INSTRUCTIONS (WHAT YOU NEED TO DO)
═══════════════════════════════════════════════════════════════════════

STEP 1: Install Python Packages
-------------------------
Find your Python installation and run:

# Option A: If pip works
pip install openai python-dotenv

# Option B: Using Python module
python -m pip install openai python-dotenv

# Option C: If you have specific Python path
/path/to/python -m pip install openai python-dotenv

STEP 2: Get OpenAI API Key
-------------------------
1. Visit: https://platform.openai.com/api-keys
2. Sign up or log in
3. Click "Create new secret key"
4. Copy the key (starts with "sk-...")

STEP 3: Configure API Key
-------------------------
Edit: backend/.env
Set:
OPENAI_API_KEY=sk-your-actual-key-here

STEP 4: Restart Backend
-------------------------
cd backend
node server.js

STEP 5: Test
-------------------------
Upload a resume through the web UI
Check backend console for: "✓ OpenAI enhancement applied"
Results will show "ai_enhancement": "enabled"
