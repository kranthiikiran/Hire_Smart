OPTION A: Docker Installation (Easiest - All Services Included)
---------------------------------------------------------------
1. Install Docker Desktop from https://www.docker.com/

2. Clone/Download the project:
   cd path/to/HireSmart_Project

3. Start all services with Docker Compose:
   docker-compose -f docker-compose.dev.yml up

4. Access the application:
   Frontend: http://localhost:5173
   Backend:  http://localhost:5000

Done! All services (MongoDB, Redis, Backend, Frontend) are running.


OPTION B: Automated Installation Script (Windows)
-------------------------------------------------
1. Open PowerShell as Administrator

2. Navigate to project directory:
   cd path\to\HireSmart_Project

3. Run installation script:
   .\INSTALL.ps1

4. Start services:
   .\START_NEW.ps1

5. Open in browser:
   http://localhost:5173

STEP-BY-STEP USAGE:

1. Register an Account
   --------------------
   - Open http://localhost:5173
   - Click "Register"
   - Fill in: Email, Password, Role (Recruiter/Candidate)
   - Click "Create Account"

2. Login
   -----
   - Enter your email and password
   - Click "Login"
   - You'll be redirected to the Dashboard

3. Create a Job Analysis
   ---------------------
   - Navigate to "Upload" page
   - Enter Job Title (e.g., "Senior React Developer")
   - Enter Job Description (detailed requirements)
   - Select Experience Level
   - Click "Continue" or "Next"

4. Upload Resumes
   --------------
   - Drag and drop PDF/DOCX/TXT files
   - Or click to browse and select files
   - Maximum 20 files per batch
   - Maximum 5MB per file
   - Click "Analyze Resumes"

5. View Results
   ------------
   - Wait for analysis to complete (2-30 seconds depending on batch size)
   - Candidates are automatically ranked by match score
   - Color-coded classifications:
     * Green: SUITABLE (75%+)
     * Yellow: PARTIALLY_SUITABLE (50-75%)
     * Red: NOT_SUITABLE (<50%)

6. Review Candidate Details
   ------------------------
   - Click on any candidate to see:
     * Matched Skills (green checkmarks)
     * Missing Skills (red crosses)
     * Additional Skills (blue plus)
     * Experience level
     * Match score breakdown
     * AI-generated summary

7. Export Results
   --------------
   - Download as PDF report
   - Export as CSV for spreadsheet
   - Export as JSON for integration

8. View History and Analytics
   ---------------------------
   - Dashboard: View overall statistics
   - History: Browse past analyses
   - Filter by date, score, classification

# ══════════════════════════════════════════════════════════════
#  SECTION 8: TROUBLESHOOTING
# ══════════════════════════════════════════════════════════════

PROBLEM: Backend won't start
SOLUTION:
- Check if port 5000 is already in use: netstat -ano | findstr :5000
- Kill existing process or change PORT in .env
- Verify Node.js is installed: node --version
- Check backend/logs/error.log for details

PROBLEM: Frontend won't start
SOLUTION:
- Check if port 5173 is in use: netstat -ano | findstr :5173
- Verify npm dependencies: cd frontend-react && npm install
- Check console for errors
- Try: npm run dev --host

PROBLEM: MongoDB connection error
SOLUTION:
- If using local MongoDB, ensure mongod is running
- Check MONGODB_URI in backend/.env
- System works without MongoDB (uses JSON storage)
- To disable MongoDB: Remove MONGODB_URI from .env

PROBLEM: Redis connection error
SOLUTION:
- Redis is optional - system works without it
- Queue will process directly without Redis
- To install Redis: Use Docker or https://redis.io/download
- Or disable by not setting REDIS_HOST in .env

PROBLEM: Python script errors
SOLUTION:
- Verify Python is installed: python --version
- Install dependencies: cd ai && pip install -r requirements.txt
- Check Python path in .env: PYTHON_PATH=python
- Try: python3 instead of python

PROBLEM: Resume text extraction fails
SOLUTION:
- Verify file format: Only PDF, DOCX, TXT supported
- Check file size: Maximum 5MB per file
- Try with a simple text file first
- Check backend logs for detailed error

PROBLEM: CORS errors in browser
SOLUTION:
- Add frontend URL to CORS_ORIGIN in backend/.env
- Example: CORS_ORIGIN=http://localhost:5173,http://localhost:3000
- Restart backend after changing .env
- Clear browser cache and try again

PROBLEM: JWT authentication fails
SOLUTION:
- Verify JWT_SECRET is set in backend/.env
- Clear browser localStorage (Application tab in DevTools)
- Re-login to get new token
- Check token expiry (default: 1 hour)

PROBLEM: File upload "413 Payload Too Large" error
SOLUTION:
- Reduce resume file size (compress PDF)
- Check MAX_FILE_SIZE in .env (default: 5MB)
- Process fewer files per batch

PROBLEM: Analysis takes too long
SOLUTION:
- Enable Redis for queue processing
- Reduce batch size (process fewer resumes at once)
- Increase QUEUE_CONCURRENCY in .env (default: 4)
- Check Python dependencies are properly installed

Production Deployment:
---------------------
1. Set NODE_ENV=production in .env
2. Use strong JWT_SECRET (64+ random characters)
3. Use MongoDB Atlas or production MongoDB instance
4. Enable Redis for better performance
5. Use Docker Compose production file:
   docker-compose -f docker-compose.prod.yml up -d
6. Set up SSL/HTTPS with nginx reverse proxy
7. Configure firewall rules
8. Set up automated backups
9. Enable monitoring and logging

Scaling for High Traffic:
------------------------
- Use MongoDB replica set
- Use Redis cluster
- Deploy multiple backend instances behind load balancer
- Use CDN for frontend static files
- Enable caching headers
- Use PM2 for process management

Security Hardening:
------------------
- Enable HTTPS only
- Set strong JWT_SECRET
- Enable rate limiting
- Use environment-specific CORS origins
- Enable MongoDB authentication
- Use Redis password
- Regularly update dependencies: npm audit fix
- Enable security headers (already configured with Helmet)
- Implement 2FA for user accounts (future enhancement)

Monitoring and Logging:
----------------------
- Backend logs: backend/logs/combined.log
- Error logs: backend/logs/error.log
- Set LOG_LEVEL in .env (debug, info, warn, error)
- Use external monitoring: DataDog, New Relic, etc.
- Set up alerts for errors and downtime

Database Backups:
----------------
# MongoDB backup
mongodump --uri="mongodb://localhost:27017/hiresmart" --out=./backups/

# MongoDB restore
mongorestore --uri="mongodb://localhost:27017/hiresmart" ./backups/hiresmart/

# Automated daily backup script (cron job):
0 2 * * * mongodump --uri="mongodb://localhost:27017/hiresmart" --out=/backups/$(date +\%Y\%m\%d)/
