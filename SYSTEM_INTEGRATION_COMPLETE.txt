# ══════════════════════════════════════════════════════════════
#                      SCORING ALGORITHM
# ══════════════════════════════════════════════════════════════

**WEIGHTED FORMULA:**
```
Final Score = (Skill Match × 60%) + (Experience × 25%) + (Semantic × 15%)
```

**SKILL MATCH (60%):**
- Matched skills from 200+ skill database
- Formula: (Matched / Required) × 100

**EXPERIENCE RELEVANCE (25%):**
- Years of experience extraction
- Level matching (Entry/Mid/Senior)

**SEMANTIC SIMILARITY (15%):**
- TF-IDF vectorization
- Cosine similarity calculation
- Context-aware matching

**CLASSIFICATION:**
- ✅ SUITABLE: Score ≥ 75%
- ⚠️  PARTIALLY_SUITABLE: Score 50-75%
- ❌ NOT_SUITABLE: Score < 50%
