============================================================
1) PROJECT OVERVIEW
============================================================
Project Name: HireSmart - AI Resume Screening System
Purpose: End-to-end resume screening using AI/NLP with candidate ranking,
authentication, dashboard analytics, and history tracking.

Core Workflow:
1. User registers/logs in.
2. Recruiter enters job title + job description.
3. Recruiter uploads resumes (PDF, DOCX, TXT).
4. Backend extracts text and sends content for NLP analysis.
5. AI engine computes skill match, semantic similarity, and experience fit.
6. System ranks candidates and classifies suitability.
7. Results are shown in dashboard and stored for history/statistics.


============================================================
2) ARCHITECTURE
============================================================
Architecture Type: Full-stack web application with AI/NLP processing
Pattern: REST API + service modules + optional queue processing

Main Layers:
- Frontend: React application (UI, routing, auth state, upload UI, charts)
- Backend: Node.js/Express API (auth, uploads, orchestration, persistence)
- AI/NLP: Python scoring service/script for semantic resume matching
- Data Layer: MongoDB models (primary) with JSON fallback mode available
- Queue Layer: Bull + Redis (primary) with direct processing fallback
- Deployment: Docker + Docker Compose + Nginx for production hosting
