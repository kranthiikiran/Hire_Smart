============================================================
1. ABSTRACT
============================================================
HireSmart is an AI-enabled resume screening web application that automates candidate evaluation for recruiters. It allows users to upload job descriptions and resumes, extracts content from resume files, computes job-fit scores using NLP techniques, classifies candidates based on suitability, and presents results through dashboards and history views. The system combines React frontend, Node.js/Express backend, Python NLP processing, and optional OpenAI enhancement.

10. HOW TO TRAIN MODEL
============================================================
Current system uses statistical NLP and rules (not heavy custom deep model training by default).

To train a custom model in future:
1. Collect labeled hiring data (resume, JD, outcomes)
2. Clean/anonymize and preprocess text
3. Build feature sets (skills, tenure, semantic vectors)
4. Train classifier/ranker (for example XGBoost/Transformer)
5. Validate accuracy, precision, recall, and fairness
6. Deploy model as versioned inference service
7. Monitor drift and retrain periodically

11. IMPORTANCE - USING MODEL OR USING AI TO HELP APPLICATION
============================================================
1. Pure keyword matching misses context and synonyms.
2. AI assistance improves semantic understanding and ranking quality.
3. Hybrid approach (rules + statistical NLP + optional GPT) is practical:
   - Better accuracy than rules only
   - Better control and explainability
   - Better reliability in production
4. AI helps recruiters make faster and more informed decisions.
