## How to Use

### Automatic Random Testing (Recommended)
1. Navigate to the Upload Resume page
2. Click the **"🎲 Analyze Random Sample"** button
3. The system will:
   - Randomly select one of the 5 samples
   - Load matching job description
   - Run AI analysis automatically
   - Display complete results

### Manual Testing
You can also manually upload any of these files:
1. Fill in job description manually
2. Upload the desired sample resume file
3. Click "🚀 Analyze Resume"
